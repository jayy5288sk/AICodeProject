# 작업 지시서

> 해당 작업이 완료되었음을 사용자에게 승인받을 경우, 이 문서를 삭제한다.
>
> 기존 파일의 수정/삭제가 필요할 경우, 반드시 사용자의 승인하에 수행한다.

---

## 작업 목적
- Github Issues 등록 스킬화.

## 작업 내용
- 워크 플로우 상의 Github Issue 등록을 스킬로 지정한다.
- `CLAUDE.md`에선 OnDemand 참조가 아닌, 스킬 호출을 통해 이슈가 등록될 수 있도록 유도한다. 
- 원본 규칙(지침) 문서를 삭제하는 것이 아닌, 스킬에서는 관련 지침 문서의 필요 섹션을 읽고 행동을 수행할 수 있도록 한다. 
- 이슈 등록 권유 혹은 이슈 작성 전의 사용자 승인 단계에서 필요한 정보를 간결하게 표현할 수 있도록 Claude의 멘트 규격을 스킬에 지정해둔다.
