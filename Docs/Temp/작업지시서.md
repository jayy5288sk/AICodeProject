# 작업지시서
> 기존 파일의 수정/삭제가 필요할 경우, 필수로 사용자에게 승인를 받는 것을 수행할 것. 

---

## 작업 목적
- Github Pull Request 등록 스킬화

## 작업 내용
- 워크 플로우 상의 Pull Request 등록을 스킬로 지정한다. 
- `CLAUDE.md`에선 OnDemand 참조가 아닌, 스킬 호출에 의거하여 Pull Request가 등록될 수 있도록 유도한다.
- 원본 규칙(지침) 문서를 삭제하는 것이 아닌, 스킬에서는 관련 지침 문서의 필요 섹션을 읽고 행동을 수행할 수 있도록 한다.
- PR 등록 전의 사용자 승인 단계에서 필요한 정보들을 간결하게 표현할 수 있도록 Claude의 멘트 규격을 스킬에 지정해둔다.
