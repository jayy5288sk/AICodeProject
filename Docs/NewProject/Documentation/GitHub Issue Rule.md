## Github Issues 작성 규칙
> Github Issues를 작성할 때의 규칙.
>
> 이슈 작성 양식은 `@Docs\Template\IssueTemplate.md`를 참고.
>
> 해당 문서는 각 섹션에 대한 작성 규칙을 정의한다. 

## 개요
- 이슈는 항상 작업을 시작하기 전에 가장 먼저 기술하여야 한다.

# 1. Title
- 20자 이내로 적는다.
- 상세한 키워드가 아닌 '기능' 단위로 적는다.
- 예시는 다음과 같다.
  
  ```markdown
  - 플레이어 이동 구현
  - 몬스터 피격 판정 구현
  - Weapon Base 클래스 생성
  ```

## 2. 배경 및 목적 
- 이슈 작성 시, 해당 섹션에 기재할 내용을 사용자에게 필수로 질문한다. 
- 해당 조건을 충족되지 않을 시 이슈 작성을 반드시 거부한다.
- 리스트로 작성하며, 불필요한 표현을 제거하여 간결하게 작성한다.
- 예시는 다음과 같다.

  ```markdown
  ## 배경 및 목적
  - 플레이어 피격 판정 시, 데미지 수치와 공격 판정에 필요한 데이터 동시 전달 필요
  - `DamageInfo` 구조체를 전달하는 방식으로 피격 판정 개선
  ```

## 3. 목표 (To-be)
- 작업이 완료 되었을 때의 예상 동작 혹은 결과를 기재한다.
- 리스트로 작성하며 불필요한 표현을 제거해 간결하게 작성한다.
- 예시는 다음과 같다.

  ```markdown
  ## 목표 (To-be)
  - 플레이어와 몬스터간 공격 판정 시, `IDamageable` 인터페이스의 `TakeDamage (DamageInfo info)`를 통해 공격 판정 개선
  - `DamageInfo` 구조체가 데미지를 주는 객체로부터 받는 객체로 전달.
  ```

## 4. 작업 내용 
- 예상되는 프로젝트의 생성, 수정, 삭제에 대한 변경사항을 기재한다.
- 리스트로 작성하며, 특정 경로의 파일에 어떤 작업이 이뤄지는지 기재한다.
- 예시는 다음과 같다.

  ```markdown
  ## 작업 내용
  - `Assets/Scrits/PlayerController.cs` 수정
  - `Assets/Scrits/Core/IDamageable.cs` 수정
  - `Assets/Scrits/Core/DamageInfo.cs` 수정
  - `Assets/Prefabs/Player/PFB_Player.prefab` 수정
  ```

## 5. 완료조건 (DoD)
- 작업을 완료 처리를 하기 전의 체크리스트 확인 목적으로 작성한다.
- `3. 목표 (To-be)` 및 `4. 작업 내용`의 내용과, 유니티 에디터에서의 에러 발생 여부를 체크리스트로 둔다.
- 예시는 다음과 같다.

  ```markdown
  ## 완료조건 (DoD)
  - [ ] 1. `PlayerController` 객체와 `MonsterController` 객체가 `IDamageable` 인터페이스를 통해서만 데미지 판정을 주고 받는다.
  - [ ] 2. `IDamageable.TakeDamage(DamageInfo info)` 메서드를 통해 공격을 시도한 객체에서 공격을 받는 객체로 `DamageInfo` 구조체가 전달된다.
  - [ ] 3. 공격을 받는 객체에서 `DamageInfo` 구조체의 정보를 받아 로그 출력에 성공했다.
  - [ ] 4. 유니티 에디터에서 Error, Warning 로그가 발생하지 않는다. 
  ```

## 6. 특이사항
- 아래의 사항에 해당되지 않으면 이 섹션은 기재하지 않는다.
  1. 해당 이슈가 진행되기 위한 선행 조건이 있는 경우
  2. `Github Issues`에 등록된 다른 Issue와 연관되어 있는 경우
  3. 해당 이슈를 통해 해소된 Blocker 및 이슈가 있는 경우
- `Github Issues`에 등록된 Issue를 언급하는 경우, 태그를 걸어둔다.  

## 7. 기타
### Label
- 이슈의 제목은 다음과 같이 작성한다.
  → 제목: `[말머리] 이슈 내용`
- 말머리에 해당하는 키워드는 다음 중 하나를 선택한다. 해당되는 Label이 등록되지 않은 경우, Label을 새로 등록하고 할당한다. 

| 타입 | 언제 쓰나 | 예시 |
|:---:|:---:|:---:|
| `[Feat]` | 새로운 기능 추가 | `[Feat] 몬스터 부채꼴 시야 감지 추가` |
| `[Bug]` | 버그 수정 | `[Bug] 체력이 0 이하에서 사망 처리되지 않던 문제` |
| `[Fix]` | 기능 변화주지 않는 코드 정리, 동작 변화 없는 구조 개선 | `[Fix] 플레이어 컨트롤러 소스 코드 리펙토링` |
| `[Docs]` | 문서 작성·수정 | `[Docs] 작업일지 2026-09-20 추가` |
