# Tech Spectification
> 이 프로젝트의 기술 스택 관련 결정 사항이다.
> Claude Code는 코드를 작성할 때 이 문서를 기준으로 한다.
>
> `미정`으로 표기된 항목은 결정 전까지 임의로 정하지 않고 사용자에게 질문한다. 결정되면 이 문서만 갱신한다.
---

## 프로젝트 제원
- 프로젝트명: 미정
- 장르: 그리드 맵 턴제 전략 게임
- 팀 구성: 1인
- 기간: 2026-11-06 (금) ~ 2026-11-23 (월)
  - 구현: 11/06 ~ 11/21 (16일), 발표 자료: 11/22 ~ 11/23 (2일)
- 구현 범위(Feature ID)와 일정의 원본: `Docs\ProjectPlan.md`

## Unity 환경
- 버전: Unity 6000.3.9f1 LTS
- 렌더 파이프라인: URP
- 빌드 플랫폼: Windows

## 시점 및 좌표계
- 시점: 3D 쿼터뷰 (비스듬히 내려다보는 시점)
  - 2D로 바꾸면 마우스 좌표 → 칸 변환 방식만 달라진다. 1일차에 확정한다.
- 칸은 **XZ 평면**에 놓인 사각 칸이며, 이동은 상하좌우 **4방향**만 허용한다.
- 칸 거리: 상하좌우로 몇 칸 떨어져 있는지로 계산한다.
- 칸 인덱스 ↔ 월드 좌표 변환 규칙: 미정 (1일차 확정)
- 마우스 → 칸 변환: 미정 (레이캐스트 등, 1일차 확정)

## 길찾기
- 다익스트라 알고리즘을 사용한다.
- Unity NavMesh는 사용하지 않는다.
- A* 적용은 선택 구현(F-25)으로, 다익스트라 구조 위에 휴리스틱을 추가하는 방식으로 확장한다.

## 외부 데이터
- 유닛, 무기, 맵 데이터는 코드 밖 데이터 파일로 분리하며, 코드 수정 없이 반영되어야 한다.
- 데이터 형식: 미정 (JSON(`JsonUtility`) 또는 CSV 중 택 1, 1일차 확정)
- 데이터 저장 위치: 미정 (빌드 환경에서도 읽히는 경로여야 함. 예: `StreamingAssets`)
- 데이터 스키마(필드 구성)의 원본: 미정 (스키마 문서 작성 후 경로 기재)

## 유저 입력 시스템
- new Input System
  - 구 `InputManager`는 사용하지 않는다.
- 특정 입력에 대한 기능 구현 시 `InputActionReference`를 사용해 InputAction을 참조하는 형태로 구현한다.
- OnEnable에서 InputAction에 대한 Enable(), OnDisable()에서 Disable()을 사용한다.

## 제외 사항
- 전투 애니메이션 컷신
- 파티클/셰이더 직접 제작 (제공받은 이펙트를 알맞은 칸/시점에 생성만 한다)
- 멀티플레이
