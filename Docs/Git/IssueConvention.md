## 이슈 방식
- 이슈는 항상 작업을 시작하기 전에 가장 먼저 기술하여야 한다.
- 이슈의 제목은 다음과 같이 작성한다.
  → 제목: `[말머리] 이슈 내용`

- 말머리에 해당하는 키워드는 다음과 같다.

| 타입 | 언제 쓰나 | 예시 |
|---|---|---|
| `[Feat]` | 새로운 기능 추가 | `[Feat] 몬스터 부채꼴 시야 감지 추가` |
| `[Bug]` | 버그 수정 | `[Bug] 체력이 0 이하에서 사망 처리되지 않던 문제` |
| `[Fix]` | 동작 변화 없는 코드 정리, 동작 변화 없는 구조 개선 | `[Fix] 플레이어 컨트롤러 소스 코드 리펙토링` |
| `[Docs]` | 문서 작성·수정 | `[Docs] 작업일지 2026-09-20 추가` |

- 이슈의 내용은 다음과 같은 형식을 따른다.

``` 
## 작업 내용
<!-- 무엇을 만드는지 한두 줄 -->
<!-- 예시: 포탑을 계속 쏘면 과열돼서 잠깐 못 쏘게 만든다 (무한 난사 방지) -->
-

- [ ] 최대치 도달 시 일정 시간 발사 불가
-->
- [ ]
```
